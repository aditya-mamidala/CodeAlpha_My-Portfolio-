# Aditya — Portfolio

A polished, responsive portfolio website built with vanilla HTML, CSS and JavaScript for the CodeAlpha Frontend Development task.

## Files
- `index.html` — all page sections and project cards
- `style.css` — dark premium design, animations, responsive layouts
- `script.js` — mobile navigation, active section tracking, reveal animations

## Sections
- Introduction
- About and design principles
- Selected work / project cards
- Skills and toolkit
- Contact section with email and social links

## Before publishing
Open `index.html` and `script.js` and customize:
- Your name, introduction, bio and skill descriptions
- The sample project descriptions and repository URLs
- The `portfolioEmail` value in `script.js` (currently `your.email@example.com`)
- GitHub and LinkedIn URLs (currently generic profile URLs)
- The stats in the hero section to reflect your real experience

The project cards are sample portfolio entries; make sure their links point to your actual repositories.
